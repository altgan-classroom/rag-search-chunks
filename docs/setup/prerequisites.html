Before Session 1: install Docker, Python and Node.js

Orca RAG project setup · Windows 10/11 and macOS · allow 30 to 60 minutes (Docker is the slow one)

Do this before the session. Everything below is free. If one method fails, try the next one for the same tool, then post the exact error message (a screenshot) in the group. Do not skip the final checklist (section 5).

1. What you need and why

ToolVersionWhy we need it in the RAG project

Your laptop: 8 GB RAM or more is comfortable (Docker is given about 4 GB), and about 10 GB of free disk. Windows: 64-bit Windows 10 or 11 with virtualization enabled. Mac: Apple silicon or Intel, on a macOS release that Docker still supports (check the Docker link at the end).

2. Check what you already have (1 minute)

Open Terminal (Mac) or PowerShell (Windows) and run:

python3 --version      # Windows: python --version   (or: py --version)
node --version
npm --version
docker --version
git --version

Anything that prints a version at or above the table is done. A "command not found" or "is not recognized" message means install that tool. On Windows, a plain python that opens the Microsoft Store means Python is not installed yet (see Troubleshooting).

3. Windows 10 / 11

Order matters a little: Docker first (it asks for a restart), then Python, then Node.js, then Git. Use PowerShell, not the old Command Prompt.

3.1 Docker Desktop

Docker Desktop needs the Windows feature WSL 2 (a light Linux layer) and CPU virtualization turned on. Docker Desktop is free for personal use, education and learning, and small businesses (under 250 employees and under USD 10 million revenue). Larger companies need a paid plan, so if you are on a work laptop from a large company, use your personal machine or ask your IT team.

Recommended Method A: winget (command line, fastest). Open PowerShell as Administrator (right-click, Run as administrator):

wsl --install
winget install -e --id Docker.DockerDesktop

Restart Windows when asked, then open Docker Desktop from the Start menu, accept the terms, and wait until the whale icon says "Engine running". If wsl --install says WSL is already installed, run wsl --update instead.

Method B Official installer. Download "Docker Desktop for Windows" from docker.com (the AMD64 build for normal laptops, ARM64 only for Snapdragon laptops), run the installer, keep "Use WSL 2 instead of Hyper-V" ticked, restart, open Docker Desktop.

Method C Alternative if Docker Desktop will not run: Rancher Desktop or Podman Desktop also work with the project's compose files, but we can only help with Docker Desktop in the sessions.

If it fails with "virtualization is disabled" / "WSL 2 requires...": restart the PC, open BIOS/UEFI (usually F2, F10, Del or Esc at the logo), and enable Intel VT-x / AMD-V (SVM Mode). Check in Task Manager, Performance, CPU: "Virtualization: Enabled". On Windows 10/11 Home this is fine, WSL 2 is what Docker uses.

Give Docker enough memory: Docker Desktop, Settings, Resources: at least 4 GB (with WSL 2 it follows WSL; if you hit memory errors, create %UserProfile%\.wslconfig containing [wsl2] then memory=4GB, then run wsl --shutdown).

3.2 Python 3.12

Recommended Method A: winget

winget install -e --id Python.Python.3.12

Close and reopen PowerShell, then run python --version. If it prints 3.12.x you are done.

Method B python.org installer. Download the Windows installer from python.org/downloads (3.12.x). On the very first screen tick "Add python.exe to PATH" before pressing Install Now. Forgot? Run the installer again, choose Modify, and tick the environment variables option.

Method C Python Install Manager (python.org's newer tool): install "Python Install Manager" from python.org/downloads/windows (or winget install 9NQ7512CXL7T), then:

py install 3.12
py -3.12 --version

With this method you start Python with py. If you use it, tell us, because a few lab commands say python.

Typing python opens the Microsoft Store? Windows has a placeholder. Turn it off: Settings, Apps, Advanced app settings, App execution aliases, switch off the two "python.exe / python3.exe" entries, reopen PowerShell. Avoid the Microsoft Store build of Python for this course.

3.3 Node.js + npm (LTS)

Recommended Method A: winget

winget install -e --id OpenJS.NodeJS.LTS

Method B Official installer: nodejs.org, download the LTS "Windows Installer (.msi)", keep the defaults (it adds Node to PATH), reopen PowerShell.

Method C Version manager fnm (handy if you juggle several projects): winget install Schniz.fnm, reopen PowerShell, then fnm install 22 and fnm use 22.

"npm.ps1 cannot be loaded because running scripts is disabled": run once Set-ExecutionPolicy -Scope CurrentUser RemoteSigned and answer Y, or run npm from Command Prompt.

3.4 Git (and make)

winget install -e --id Git.Git

The lab uses make, which Windows does not have. You do not need it: the lab guide lists the plain commands for each make target. If you want make anyway: winget install ezwinports.make (reopen PowerShell). Prefer a Linux-like setup? wsl --install gives you Ubuntu where everything works as on macOS, and Docker Desktop's WSL integration can be switched on in its Settings. The Windows route of the lab has not been tested by the instructors, so tell us what you hit.

4. macOS

Everything works on Apple silicon (M1/M2/M3/M4) and Intel Macs, but download the matching Docker build. Check yours: Apple menu, About This Mac ("Chip: Apple..." or "Processor: Intel").

4.0 Command line tools (git and make)

xcode-select --install

A window appears; click Install and wait. This gives git and make. (Skip it if git --version already works.)

4.1 Docker Desktop

Recommended Method A: official installer. From docker.com download "Docker Desktop for Mac" for Apple silicon or Intel, open the .dmg, drag Docker to Applications, start it, accept the terms, and enter your Mac password when it asks to install its helper. Wait until it shows "Engine running". Free for personal use, education and small businesses (see the Windows note above).

Method B Homebrew: brew install --cask docker-desktop. Homebrew renamed this cask from docker; run brew update first. On some Homebrew versions the cask fails with a definition error; if you see that, use Method A.

Method C Lightweight alternatives: Colima or OrbStack, if Docker Desktop is too heavy for your Mac:

brew install colima docker docker-compose
colima start --memory 4

Memory: Docker Desktop, Settings, Resources, Memory: set at least 4 GB.

4.2 Python 3.12

The Python that ships with macOS or the command line tools can be old (3.9), which is too old for this project. Check with python3 --version; install 3.12 if it prints less than 3.11.

Recommended Method A: python.org installer. Download the macOS 64-bit universal2 installer (3.12.x) from python.org/downloads, open the .pkg, click through. Then open a new Terminal and run python3 --version.

Method B Homebrew:

brew install python@3.12
python3.12 --version

If python3 still shows an old version, use python3.12 explicitly, or add to ~/.zshrc: export PATH="$(brew --prefix python@3.12)/libexec/bin:$PATH", then open a new Terminal.

Method C uv (a fast Python tool): brew install uv then uv python install 3.12.

No Homebrew yet? Install it from brew.sh (one command shown on the home page), then follow the instructions it prints at the end to add brew to your PATH.

4.3 Node.js + npm (LTS)

Recommended Method A: official installer. nodejs.org, download the LTS macOS installer (.pkg), click through, open a new Terminal.

Method B Homebrew:

brew install node@22
brew link --overwrite --force node@22

(node@22 is installed "keg-only", so the second command is what puts node and npm on your PATH.)

Method C nvm (version manager): follow the install command on github.com/nvm-sh/nvm, open a new Terminal, then nvm install --lts.

6. Troubleshooting

ProblemFix
docker: command not found / "cannot connect to the Docker daemon"Docker Desktop is not running. Open it and wait for "Engine running". On Windows, also check WSL: wsl --status.
Docker Desktop stuck on "starting" (Windows)wsl --update, then wsl --shutdown, restart Docker Desktop. Confirm virtualization is enabled in BIOS.
Docker is very slow or containers get killedRaise memory to 4 GB or more (Docker Settings, Resources). Close other heavy apps.
python or pip not recognized (Windows)Reopen PowerShell. Still failing: rerun the Python installer, Modify, tick "Add Python to environment variables". Also check the Store alias note in 3.2.
python3 --version shows 3.9 or 3.10 (Mac)Install 3.12 (section 4.2) and use python3.12, or fix PATH as shown, then open a new Terminal.
node or npm not found after installClose and reopen the terminal. On Mac with Homebrew, run the brew link line.
npm ci fails with permission errorsDo not use sudo. Reinstall Node from nodejs.org (or use nvm/fnm), which installs into your user folder.
Corporate laptop with proxy / admin rights missingUse a personal machine, or ask IT to install Docker Desktop, Python and Node for you. Tell us early.
